# Session D1: test-order and isolation check (C005)

Owner approval: Ani Dey approved D1-D5 on 18 Nov 2026, including the check-semantics changes.

Plan
- New check C005 "Test order and isolation" in src/aethens/checks/c005_order.py, plus a small
  stdlib-only driver (src/aethens/sandbox/order_driver.py) that runs INSIDE the sandbox, never in
  the Aethens process. The driver reuses unittest's own argument parsing and discovery
  (`unittest.TestProgram` with `runTests` overridden), then runs the discovered tests in a given
  order and prints per-test outcomes on one marker line.
- Orders: the verifier's default order (baseline), reversed, N seeded shuffles (shuffled within
  modules, classes and methods, like pytest-randomly, so class and module fixtures stay grouped),
  and each test alone in a fresh container. Every C005 run of a task uses the same PYTHONHASHSEED,
  so only the order changes.
- A verdict change is reported only if it reproduces: the changed order and the baseline are each
  run a second time. Changes that do not reproduce are info (C002's territory).
- Supported verifiers: `python -m unittest ...` (any unittest arguments). Anything else gets one
  info finding saying C005 checked nothing (as C004 does), so a silent C005 is never a clean bill.
- Budget: shuffles smoke 1 / standard 2 / deep 5; isolated tests capped at 10 / 30 / 200.
- Bench: order-alphabetical and order-generated now expect C005. New planted fixtures:
  order-crossmodule (a later module patches shared state, caught by reorder only) and
  order-classfixture (a test mutates a setUpClass fixture, caught by isolation and reorder).
  New controls: ctrl-order-cache (memoised gold, independent tests) and ctrl-order-shared-readonly
  (shared read-only class fixture and module constant).
- Tests first: tests/test_c005_unit.py (fake runner), tests/test_order_driver.py (pure ordering
  functions in-process; driver end to end in Docker), bench fixture tests.

Cannot verify
- pytest verifiers (the default image has no pytest and runs have no network); unsupported, info.
- Order dependence that only shows with orders we did not try (the shuffles are a sample).
