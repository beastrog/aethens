# Session B6: reports, CLI, bench metrics

Plan
- docs/report-schema.json: JSON Schema (draft 2020-12) for aethens-report/v1, matching models.Report.
- src/aethens/report.py: `render_json`, `render_markdown` (PR-comment sized; library returns strings).
- CLI: `aethens audit PATH [--budget] [--fail-on error|warning] [--format json|markdown] [--seed N]
  [--unsafe-local] [--check ID] [--output FILE]`; exit 0 pass, 1 findings at or above fail-on,
  2 tool error, 3 timeout (defined below). Only cli/ prints.
- bench/run_bench.py (`make bench`): audits every manifest task (all checks, budget standard, seed 0),
  computes precision, recall, false positives, unexpected findings, per check and per class,
  writes bench/results.json (deterministic: no timings) and compares with bench/baseline.json; exits
  1 on regression. `--update-baseline` rewrites the baseline (owner action).
- Bench grows to 22 tasks: + 3 order-dependence (2 surfaced through hash order, 1 pure alphabetical
  order dependence that no v0.1 check can see: a planted known miss), + 4 tricky controls.
- Tests first: tests/test_report.py (schema validation of real and fake reports, markdown content, no
  overclaiming), tests/test_cli.py (exit codes 0/1/2/3, formats, fail-on, warning text for
  --unsafe-local), tests/test_bench_metrics.py (pure metric and gate functions).

Exit code 3 definition (agent decision, needs owner confirmation): 3 when any gold-solution run in
C001 or C002 hit its timeout, because then the audit could not establish the gold verdict. Precedence:
2 (tool error) > 3 (timeout) > 1 (findings at or above fail-on) > 0.

## Results (2026-11-18, local, Docker Engine 29.10.0, seed 0, budget standard)

- `make bench`: 22 tasks (8 controls, 14 defective). precision 1.0, recall 0.8571 (12/14),
  false positives 0, unexpected 3 (C001 errors on the flaky and order-setcases tasks: the single C001
  gold run failed by chance, which is true), info on controls 2 (C004 equivalent mutants on ctrl-clamp).
- Determinism: two consecutive `bench/run_bench.py` runs produced byte-identical bench/results.json.
- Injected regression: C002 temporarily made to return no findings. `make bench` printed
  `bench: REGRESSION: recall 0.6429 < baseline 0.8571`; run_bench exited 1 and make failed (exit 2).
  The change was reverted before committing.
- Misses: order-generated (probabilistic: all 5 C002 runs at seed 0 happened to run "pop" first, so
  the gold failed consistently; about a 1 in 16 chance) and order-alphabetical (structural: no v0.1
  check reorders tests). The fixture and the seed were NOT changed after seeing the miss.
- Every finding in a sample report (weak-sign, smoke, seed 4: C003 and C004 findings) was reproduced by
  running its repro command (tests/test_cli.py).
