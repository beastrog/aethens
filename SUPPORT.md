# Support

Aethens is an open-source project. Maintainers help as time allows; there is no SLA.

## How to get help

| Kind of request | Where to go |
| --- | --- |
| "How do I…?" or a design idea | [GitHub Discussions](https://github.com/beastrog/aethens/discussions) |
| A crash, a wrong exit code, or unexpected behaviour | [Bug report](https://github.com/beastrog/aethens/issues/new?template=bug_report.yml) |
| A finding Aethens got wrong | [False positive](https://github.com/beastrog/aethens/issues/new?template=false_positive.yml) |
| A new check or a feature | The [new-check](https://github.com/beastrog/aethens/issues/new?template=new_check_proposal.yml) or [feature](https://github.com/beastrog/aethens/issues/new?template=feature_request.yml) templates |
| You ran Aethens on real tasks | ["I ran Aethens on X"](https://github.com/beastrog/aethens/issues/new?template=ran-it.yml) |
| A vulnerability in Aethens | [Private vulnerability reporting](https://github.com/beastrog/aethens/security/advisories/new) — see [SECURITY.md](SECURITY.md) |

A Discord server may be added later. There is no invite yet; do not look for support in unofficial channels that claim to be official.

## Before you ask

- Read the [README](README.md), [task format](docs/task-format.md), and [CONTRIBUTING.md](CONTRIBUTING.md).
- Include `aethens --version` (or the commit), your OS, Python and Docker versions, the command you ran, and a minimal task directory if you can share one. Do not paste secrets.
- Please do not name defects in other people's benchmarks in a public thread before their maintainers have been told privately; see [docs/DISCLOSURE.md](docs/DISCLOSURE.md).

## Private or commercial questions

Do not send credentials, private task sets, or exploit details to a public issue. If you need a private channel for a commercial question, use the maintainer contact once one is published, or GitHub's private vulnerability reporting when the topic is a security issue.
